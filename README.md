# Тёплый сад

Сайт частной практики Виктории Горбачевой. Главная страница объединяет разделы с постоянными якорями. Архив визуальных вариантов находится по адресу `/concepts/`.

Требования и критерии приёмки, включая верхнюю навигацию и Sticky Header, — в [docs/requirements.md](docs/requirements.md).

## Навигация

Боковой навигации нет. Шапка верхняя горизонтальная и закреплённая: имя слева, сгруппированное меню и кнопка «Записаться» справа. На компьютере группы раскрываются выпадающими списками, на телефоне — модальным меню. Состояние прокрутки переключается классом `data-scrolled`, высота шапки измеряется и используется для отступа якорной прокрутки, анимации отключаются при `prefers-reduced-motion: reduce`. Код — `src/components/site-header.tsx`, стили — `src/app/navigation.css`.


## Разработка

Node.js 24, npm, Next.js App Router. Установка — `npm ci --ignore-scripts`. Локальный просмотр — `npm run dev`. Проверки — `npm run typecheck` и `npm run build`. Для статического сервера используется каталог `out/`. Параметры Timeweb App Platform Frontend — корень репозитория, Node.js 24, сборка npm run build, выход out, SSR выключен.

## Публикация на GitHub Pages

Рабочая ссылка для отправки клиентам — `https://<логин>.github.io/ViSite/`. Публикация выполняется автоматически: workflow `.github/workflows/deploy-pages.yml` собирает проект при каждом пуше в `main` и выкладывает каталог `out/` (источник Pages — GitHub Actions, в настройках репозитория выбран режим «GitHub Actions»).

Проект живёт по подпути `/ViSite/`, поэтому сборка получает переменную `NEXT_PUBLIC_BASE_PATH` — она задаётся в workflow как `/${{ github.event.repository.name }}`. Она включает `basePath` в `next.config.ts` и префиксует абсолютные ссылки и картинки (`src/lib/base-path.ts`). Для корневого домена переменную не задавайте. Файл `out/.nojekyll` добавляется на этапе публикации, иначе GitHub Pages скрывает каталог `_next`.

## Редактирование

- `src/content/practice.json` содержит согласованные публичные тексты из разделов 8–12 ТЗ. При изменении условий обновите все связанные формулировки, в том числе первый экран и FAQ.
- `src/content/settings.ts` содержит публичные контакты, ссылки, цены и описания товаров, изображения, документы и материалы. Для бесплатного файла укажите название, описание, публичный URL и `download: true`. Для статьи используйте `download: false`.
- Для бронирования укажите HTTPS-ссылку на личный Telegram. Публичный канал задаётся отдельно. Пока ссылка отсутствует, кнопка ведёт к объяснению в контактах.
- Для открытия продаж предоставьте обложку, состав, формат, подтверждённый HTTPS-адрес платёжной страницы каждого товара, почту поддержки и документы. Перед `deliveryVerified: true` проверьте внешний сценарий оплаты, отказа, отмены, задержки, повторного уведомления, отправки и повторного получения письма. Цена на внешней странице должна совпадать с каталогом. Чеки, согласия, подтверждение заказа и защищённая выдача купленного файла относятся к внешней интеграции.
- Платные файлы и секреты хранятся вне репозитория и публичной сборки. В проекте нет сбора заявок, обработки карт и хранения заказов.
- После утверждения домена задайте переменную сборки `SITE_ORIGIN` с полным HTTPS-адресом. Она включает индексацию основной страницы и её адрес в карте сайта. Аналитика требует согласования сервиса и документов. После правок пересоберите сайт.

## Графика и движение

Шрифты и иллюстрации размещены локально. Портрет, дипломы, реальные обложки и материалы ожидаются от заказчика. Обложки остаются видимыми в статическом HTML. Для мыши доступны небольшие эффекты по мотивам In View (Motion Primitives) и Tilted Card (React Bits). Модуль Motion загружается при приближении обложек к области просмотра. Системная настройка уменьшенного движения и сенсорные устройства получают статичный вариант.
Для диплома можно указать путь thumbnail к уменьшенному изображению, а url — к полному документу. Для аудиоматериала задайте audio: true. Плеер загружает аудио по действию посетителя.

Объёмный сад представлен локальным изображением WebP. CSS и Motion используются для небольших реакций обложек. Для Rive потребовался бы отдельный анимационный файл и проигрыватель, для Spline или Three.js — сцена и графический рантайм. Текущая композиция передаёт объём через готовое изображение и остаётся доступной в статической сборке.
